# انتقال بيانات الكتالوج إلى الواجهة

واجهة React لا تحتفظ بقائمة محلية للمطاعم أو المنتجات. مستودع الكتالوج يطلب
الفئات والمتاجر وقوائم المنتجات من FastAPI، ثم يحوّل استجابات API إلى نماذج
العرض. لذلك أسماء المتاجر والمنتجات والأسعار والتوافر وروابط الصور المعروضة
تأتي من سجلات MySQL.

ملف `back/app/ordering/data/demo-catalog.json` يستخدمه الباك إند فقط كمدخل للمزامنة بواسطة
`back/scripts/seed_catalog.py`. الواجهة لا تستورده ولا تستبدل به بيانات قاعدة
البيانات عند تعطل الاتصال؛ في هذه الحالة تعرض حالة الخطأ للمستخدم.

رابط صورة الغلاف والمنتج محفوظ في عمود `artwork`، ومسار الشعار محفوظ في عمود
`logo`، وتصل القيمتان إلى React ضمن استجابة API. يقبل مكوّن الصور روابط
HTTPS من مضيفي الصور المستخدمين في الكتالوج، وسياسة CSP تسمح بهذين المضيفين
فقط إضافةً إلى صور نفس الموقع وبيانات الصور المحلية.

## مسار قراءة البيانات

```text
جداول MySQL للمتاجر والفئات والمنتجات
        ↓
مسارات المطاعم والكتالوج في FastAPI
        ↓
HttpCatalogRepository ثم تحويل DTO إلى نماذج التطبيق
        ↓
صفحات React وبطاقات المتاجر والمنتجات
```

العينة المعدة للمزامنة تتكون من 8 متاجر و24 منتجًا. لم تُزرع في قاعدة
الاستضافة بعد بسبب تعذر الاتصال بعنوان MySQL الحالي. الأسماء والصور تعود
لأصحابها، والأسعار والتقييمات وأوقات التوصيل أمثلة وليست بيانات مخزون محدثة أو
دلالة على وجود شراكة تجارية.
