# Sprint 2 — دليل التنفيذ الحالي

الدليل الأساسي الذي يطابق الكود الحالي موجود في [README_SPRINT_2.md](../README_SPRINT_2.md). يشرح نطاق السبرنت، Clean Architecture المبسطة، جداول MySQL والعلاقات، endpoints، خطوات الدفع، الأمان والتشغيل.

يشمل التنفيذ Backend FastAPI وواجهة React مترابطة عبر HTTP repositories؛ كتالوج الواجهة يأتي من MySQL عبر API، ولا يوجد وضع Demo بديل للمتاجر والمنتجات. توجد سلة لكل مستخدم ومتجر، ويُنشأ طلب مستقل لكل متجر. الدفع الإلكتروني يستخدم Paymob Hosted Checkout عند ضبط المفاتيح ومعرفات التكامل، والتحويل عبر InstaPay يحتاج مراجعة موظف مخول. محاكاة الدفع مخصصة لبيئات التطوير ولا تجمع أموالًا.

Migration `20261031_0004` تضيف الجداول والقيود اللازمة. الكود محلي ولم تُطبق هذه migration على قاعدة الاستضافة ولم يُنشر هذا التغيير. مفاتيح Paymob لم تظهر بعد في الإعداد المحلي؛ ملف الإعدادات في `back/.env.payments.development` مستبعد من Git.

لم تتم إضافة أو تشغيل test suites حسب طلب صاحب المشروع. نتيجة فحوص البناء والمراجعة اليدوية في [SPRINT_2_VERIFICATION.md](../../docs/SPRINT_2_VERIFICATION.md)، ومراجعة تسليم الباك الأصلي في [SPRINT_2_REVIEW.md](SPRINT_2_REVIEW.md).
