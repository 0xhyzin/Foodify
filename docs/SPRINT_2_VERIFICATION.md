# Sprint 2 — سجل التحقق بتاريخ 2026-10-31

هذا السجل يصف الحالة الحالية بعد الإصلاح، ولا يعتمد على تجربة Demo قديمة ببيانات داخل React. لم تُضف أو تُشغّل test suites وفق طلب صاحب المشروع.

## قاعدة البيانات والباك

- المحلي: `/health/ready` رجع `200`، وAPI المطاعم رجع 8 متاجر، والتصنيفات 16، وقوائم المنتجات تُقرأ من MySQL.
- الإنتاج كان عند migration `20261020_0001` من دون جداول الكتالوج. تم حفظ نسخة محلية مشفرة قبل التعديل، ثم تطبيق migrations حتى `20261031_0005`.
- تمت مزامنة 8 متاجر و24 منتجًا و16 تصنيفًا في MySQL الإنتاج، مع التحقق من ثبات عدد الحسابات الموجودة.
- `/health/ready` بالإنتاج رجع `200` و`{"status":"ready"}`؛ الفحص يشمل MySQL وValkey وتوافق schema مع الكود.
- قراءة المطاعم والتصنيفات من `/api/v1/*` على نطاق Vercel رجعت `200` وبيانات من قاعدة الإنتاج.
- حزمة Python تحتوي JSONs الخاصة بالـseed؛ تمت قراءة الموارد من ملف wheel خارج المشروع بنجاح.
- فحص Python syntax و`git diff --check` نجحا.

## الواجهة

- TypeScript و`build:production` نجحا بعد الإصلاح.
- مراجعة يدوية في Chromium: الرئيسية تعرض 8 متاجر، وصفحة ماكدونالدز تعرض 3 منتجات بصورها وأسعارها من API المحلي.
- الضغط على إضافة منتج كزائر ينقل إلى تسجيل الدخول. `401` من استعادة جلسة غير موجودة متوقع، ولا يعني فشل قراءة الكتالوج العام.
- روجع منع ردود قديمة من مسح تحديث أحدث للسلة أو المفضلة، وعزل البيانات عند تغيير الحساب.
- أزيل قص قائمة الإدارة عند 24 متجرًا وقائمة المنتجات عند 1000 منتج؛ التحميل يتبع pagination من الباك.
- الدفع يميز انتظار التجهيز عن النتيجة غير المحسومة، ويمنع تكرار الدفع عند الحاجة إلى مراجعة الدعم.

## الدفع وحدود التحقق

- إعدادات Paymob المحلية أضيفت إلى الباك المنشور؛ الأسرار محفوظة كأسرار الاستضافة و`PAYMOB_LIVE=false`.
- هذا إعداد Sandbox؛ لم يُنفذ شراء أو تحصيل فعلي أو رد أموال. نجاح إعداد المفاتيح لا يثبت إكمال عملية دفع لدى المزود.
- مراجعة HMAC وملكية الطلب والتحقق من المبلغ تمت على الكود.
- InstaPay يظل غير متاح حتى يضبط مستلم حقيقي واسمه؛ لم تُختلق بيانات حساب بنكي.
- لم يُجر تسجيل Google/Facebook بحساب مستخدم أو إرسال بريد أثناء هذه المراجعة.
- Docker يعمل محليًا، لكن بناء وإعادة تشغيل الحاويات غير متاحين للجلسة بسبب صلاحيات Docker socket. الصورة تنسخ `app/` الذي أصبح يحتوي ملفات الكتالوج.
- لم تتم إضافة أو تشغيل unit/integration/end-to-end test suites.
